| ID      | Règle                                                                 | Détection                                                                                                                                                                                                 | Justification                                                                                                                                                                                                                                                                 |
|---------|-----------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| GCI-I01 | VM surdimensionnée avec workload containerisable                     | Détecte une VM (ex: aws_instance, azurerm_virtual_machine) dont le user_data / provisioner installe Docker ou docker-compose                                                                              | → Suggérer un service conteneur managé (ECS, AKS, Cloud Run) qui mutualise les nœuds et évite une VM dédiée                                                                                                                                                              |
| GCI-I02 | VM sans auto-scaling                                                  | Détecte un aws_instance / azurerm_virtual_machine sans association à un ASG / VMSS                                                                                                                      | → Une VM fixe tourne 24/7 même à vide ; un auto-scaling group permet de scaler à 0 la nuit                                                                                                                                                                               |
| GCI-I03 | Multiples VM identiques → suggérer un pool                             | Détecte N (≥3) ressources VM avec le même instance_type / image dans le même module                                                                                                                      | → Mutualiser via un cluster / node pool réduit l'overhead par VM                                                                                                                                                                                                          |
| GCI-I04 | Instance type non ARM (Graviton/Ampere)                                | Détecte un instance_type de la famille x86 (ex: m5.large) quand un équivalent ARM existe                                                                                                                 | → ARM consomme ~40% moins d'énergie à performance comparable ¹ (cogentinfo.com)                                                                                                                                                                                           |
| GCI-I05 | Workload événementiel sur VM → suggérer FaaS                          | Détecte une VM / conteneur avec un cron schedule et un runtime léger (Python, Node) sans trafic réseau entrant                                                                                           | → Lambda / Cloud Functions = 0 consommation au repos                                                                                                                                                                                                                     |
| GCI-I06 | Lambda/Function avec mémoire surdimensionnée                          | Détecte memory_size > 512 sans justification (timeout court, pas de traitement lourd visible)                                                                                                            | → Réduire la mémoire diminue proportionnellement l'énergie facturée                                                                                                                                                                                                       |
| GCI-I07 | Container en CronJob avec image lourde                                | Détecte un CronJob K8s dont l'image est > tag latest ou sans hash, sans multi-stage build                                                                                                                | → Chaque exécution re-pull une image lourde = bande passante + stockage gaspillés                                                                                                                                                                                          |
| GCI-I08 | BDD provisionnée en taille fixe → suggérer serverless/flexible        | Détecte aws_rds_instance / azurerm_mssql_database avec SKU fixe sans autoscaling                                                                                                                         | → Azure SQL Serverless, Aurora Serverless v2 = scale-to-zero, pas de gaspillage hors pic                                                                                                                                                                                    |
| GCI-I09 | Réplica de lecture sans justification de trafic                        | Détecte un aws_rds_instance avec replicate_source_db dans un module sans load balancer ou route read/write split                                                                                         | → Un réplica consomme autant qu'un primaire ; inutile s'il n'est pas exploité                                                                                                                                                                                                |
| GCI-I10 | Stockage BDD surdimensionné                                           | Détecte allocated_storage > 100 avec max_allocated_storage non défini (pas d'autoscaling)                                                                                                                 | → Pré-allouer un gros disque = énergie de stockage gaspillée                                                                                                                                                                                                               |
| GCI-I11 | NAT Gateway sans justification                                        | Détecte un aws_nat_gateway dans un VPC où les subnets privés ne contiennent que des services managés (Lambda, Fargate)                                                                                  | → NAT Gateway = composant actif 24/7 + coût data ; des VPC endpoints sont souvent suffisants                                                                                                                                                                               |
| GCI-I12 | Load balancer multi-AZ pour un seul backend                           | Détecte un ALB/NLB avec un seul target group contenant 1 instance                                                                                                                                        | → Overhead réseau et énergétique disproportionné pour un single-point                                                                                                                                                                                                     |
| GCI-I13 | Transfert inter-région sans CDN                                       | Détecte un S3/Blob exposé publiquement sans CloudFront/CDN devant                                                                                                                                        | → Chaque requête traverse le backbone ; un CDN réduit le trafic long-courrier                                                                                                                                                                                             |
| GCI-I14 | Pas de lifecycle policy sur le stockage objet                         | Détecte un aws_s3_bucket / azurerm_storage_account sans règle de transition vers Glacier/Cold/Archive                                                                                                     | → Données dormantes sur du stockage chaud = énergie gaspillée                                                                                                                                                                                                               |
| GCI-I15 | Volume EBS/Disk non attaché ou sans snapshot cleanup                  | Détecte un aws_ebs_volume sans attachment dans le même module                                                                                                                                           | → Disque orphelin = énergie de réplication sans utilité                                                                                                                                                                                                                     |
| GCI-I16 | Logs sans rétention                                                   | Détecte un aws_cloudwatch_log_group sans retention_in_days                                                                                                                                               | → Logs infinis = stockage croissant sans valeur                                                                                                                                                                                                                             |
| GCI-I17 | Ressource sans tag d'environnement                                     | Détecte des ressources sans tag environment / schedule                                                                                                                                                   | → Impossible d'éteindre les env non-prod la nuit sans ces tags                                                                                                                                                                                                            |
| GCI-I18 | Pas de scale-to-zero sur les env non-prod                             | Détecte un ASG/VMSS avec min_size > 0 et un tag environment=dev/staging                                                                                                                                 | → Env de dev allumés 24/7 = ~70% d'énergie gaspillée                                                                                                                                                                                                                      |
| GCI-I19 | Région à forte intensité carbone                                      | Détecte une région cloud connue pour son mix carboné élevé (ex: us-east-1 vs eu-west-1 Irlande) quand le workload n'a pas de contrainte de latence                                                        | → Choisir une région alimentée en renouvelable ² (tenesys.io)                                                                                                                                                                                                               |
| GCI-I20 | Image Docker sans multi-stage build                                   | Détecte un Dockerfile référencé avec un FROM unique sur une image lourde (ubuntu, node)                                                                                                                  | → Image plus grosse = plus de stockage, plus de bande passante, plus de temps de démarrage                                                                                                                                                                                 |
| GCI-I21 | Pas de requests/limits (déjà GCI1040)                                | Vérifie que chaque container Kubernetes déclare ses resources                                                                                                                                           | → Prérequis à tout bin-packing efficace                                                                                                                                                                                                                                     |
| GCI-I22 | Réplicas fixes sans HPA                                               | Détecte un Deployment avec replicas > 1 sans HorizontalPodAutoscaler associé                                                                                                                              | → Pods inutiles en heures creuses                                                                                                                                                                                                                                          |
